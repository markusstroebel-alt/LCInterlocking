# ScrewInNut Randfraesung

## Zweck
Optionale Stufenfraesung auf der Mutterseite fuer Einschraubmuttern mit Bund oder Rand.

## Verwendung
Bei einer ScrewInNut-Verbindung wird die Randfraesung aktiviert. Danach werden ihr Durchmesser
und ihre Tiefe angegeben. Sie wird konzentrisch zur Eindrehmutter-Tasche auf derselben
Plattenseite gefraest.

Die globalen Standardwerte stehen unter Edit -> Preferences -> LCInterlocking bereit.

## Unveraenderte Masse
Die Randfraesung beeinflusst nicht die Schraubenlaenge, den Schraubenkanal, die Washer-Dicke,
die Muttertiefe, den Gewindefreiraum oder den Imbus-Zugang.
