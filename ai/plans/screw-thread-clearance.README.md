# Feature: Klare Screw-Masse

## Zweck
Der Screw-Verbindungstyp trennt Schraubenlaenge, Mutterhoehe, Mutterntaschen-Ueberstand und
Gewinde-Freiraum hinter der Mutter. Dadurch ist eindeutig steuerbar, wie weit die Schraube durch
die Mutter reicht und wie viel Platz das ueberstehende Gewinde bekommt.

## Neue Angaben
- **Screw length**: reale Schraubenlaenge.
- **Nut height**: axiale Hoehe der Mutterntasche.
- **Nut slot overhang**: zusaetzlicher Ueberstand der Mutterntasche, Default 0.5 mm.
- **Thread clearance**: zusaetzlicher Freiraum hinter der Mutterntasche, Default 3.0 mm.

Die Defaults koennen zentral in den FreeCAD-Einstellungen gesetzt werden; Verbindungen koennen sie
anschliessend individuell ueberschreiben.
