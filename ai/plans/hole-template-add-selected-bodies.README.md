# Bodies waehrend der Bearbeitung hinzufuegen

Im Dialog **Hole templates** kann **Add selected bodies** auch nach dem Oeffnen
des Dialogs verwendet werden. Dazu weitere Komponenten im 3D-Fenster
auswaehlen, den Button druecken und die neuen Eintraege anschliessend als
Template oder Ziel zuordnen.

Bereits vorhandene Bodies werden nicht erneut hinzugefuegt. Die Auswahl wird
erst beim Druecken des Buttons gelesen, damit sie zwischen mehreren
Erweiterungen frei angepasst werden kann.

Nach dem Hinzufuegen liegen die Bodies neutral unter `Selected bodies`. Mit
**Set as template** oder **Set as target** wird ihre Rolle festgelegt.
