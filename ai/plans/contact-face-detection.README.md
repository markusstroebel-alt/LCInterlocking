# Kontaktflaechen erkennen und Verbindungstyp aendern

Dieses Feature schlaegt innerhalb der Parts eines geoeffneten MultiJoin planare
Kontaktflaechen vor. Ausgewaehlte Treffer werden als gewoehnliche Interlocking-Faces
angelegt und bleiben voll konfigurierbar. Ein Dialog waehlt, welche Seite eines
Kontaktpaars die Verbindung erzeugt.

Der Verbindungstyp einer Master-Face kann anschliessend geaendert werden. Verknuepfte
Faces aus `Add same faces` uebernehmen den Typ und die gemeinsamen Werte weiterhin von
ihrer Master-Face. Die globale Kontakt-Toleranz wird unter Edit -> Preferences ->
LCInterlocking eingestellt und ist standardmaessig `0.01 mm`.
