# Durchgehende Feder-und-Nut-Verbindung

Dieses Feature ergaenzt Interlocking um eine durchgehende Feder mit passender
Nut. Es richtet sich an Verbindungen wie Schubladenboeden, bei denen eine Platte nur
mit einem Teil ihrer Materialdicke in eine tiefe Nut greift.

Die Feder geht von der ausgewaehlten Master-Face aus. Ihre Tiefe, volle oder eigene
Hoehe und ihre Lage ueber die Materialdicke werden eingestellt. Die Seitenlage wird
mit Center, Side A oder Side B gewaehlt und im Preview kontrolliert.

Die Nuttiefe wird ueber Groove depth eingestellt. Groove bottom clearance erzeugt
zusaetzlichen Freiraum hinter der Feder. Die vorhandene Slot-width-Tolerance stellt
das Spiel in der Federhoehe bereit.
