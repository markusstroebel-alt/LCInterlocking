# Lochschablonen fuer Assembly-Verbindungen

Das Feature erzeugt neue Teile mit Bohrungen oder Taschen aus den geometrischen
Ueberlappungen von Beschlaegen und Zielteilen. Es richtet sich an Schrauben,
Bolzen, Scharniere, Auszuege und vergleichbare Koerper in einer FreeCAD-
Assembly.

## Vorgesehene Nutzung
1. Alle beteiligten Koerper markieren.
2. Den Befehl **Lochschablonen** in der LCInterlocking-Workbench starten.
3. Im Dialog Beschlaege als Schablonenkörper und zu bearbeitende Teile als
   Zielkoerper festlegen.
4. Vorschau pruefen und bestaetigen.

Die Originalkoerper bleiben erhalten. Fuer jedes Zielteil entsteht ein eigenes
Ergebnisobjekt, dessen Ausschnitte exakt den schneidenden Schablonengeometrien
entsprechen.
