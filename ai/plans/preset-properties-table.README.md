# Feature: Globale Presets als editierbare Tabelle

## Zweck
Globale Verbindungs-Presets koennen jetzt direkt in den FreeCAD-Einstellungen betrachtet und
bearbeitet werden.

## Nutzung
Unter **Edit -> Preferences -> LCInterlocking** befindet sich die Tabelle **Global connection
presets**:
- Jede Zeile ist ein Preset.
- Verbindungstyp, Name und alle gespeicherten Property-Werte sind editierbar.
- **Add preset** legt eine neue Tabellenzeile an.
- **Delete selected** entfernt ausgewaehlte Zeilen.
- **Save presets** schreibt die Tabelle in die globale Preset-Datei.

Die bestehende Preset-Auswahl in den Verbindungspanels bleibt kompatibel.
